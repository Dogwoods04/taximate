# 택시메이트 (Siheung Taxi-Mate) 소개

> 시흥에서 **같은 방향으로 가는 이웃끼리 택시 한 대를 함께 타고 요금을 나누도록** 이어 주는 웹 서비스입니다.
> 이 문서는 프로젝트를 처음 보는 사람을 위한 안내서입니다. 코드를 몰라도 1~4장만 읽으면 서비스를 이해할 수 있습니다.

- 공개 체험 주소: https://dogwoods04.github.io/taximate/
- 저장소: https://github.com/Dogwoods04/taximate
- 현재 단계: **MVP(시험판)**. 공개 테스트는 백엔드가 켜져 있을 때만 동작합니다.

---

## 1. 어떤 문제를 푸나요?

- 택시는 혼자 타면 비싸고, 같은 시간에 같은 방향으로 가는 사람은 생각보다 많습니다.
- 하지만 낯선 사람과 "같이 타실래요?"를 정하기는 어렵습니다. 누가 어디로 가는지 모르고, 만날 장소·시간을 맞추기도 번거롭습니다.
- 택시메이트는 **출발지와 목적지가 가까운 사람**을 자동으로 찾아 한 방에 모으고, 만날 장소·시간을 채팅으로 정한 뒤 **요금을 똑같이 나누도록** 돕습니다.

> 택시 호출, 배차, 결제, 요금 자동 정산은 하지 않습니다. 사람과 사람을 이어 주고 약속을 정하는 데까지만 돕습니다.

---

## 2. 한눈에 보는 사용 흐름

| 단계 | 화면 | 하는 일 |
| --- | --- | --- |
| 1 | 시작 | 카카오 로그인 또는 닉네임으로 체험하기 |
| 2 | 가입 단계 | 이름 → 성별(다른 사람에게 비공개) → 위치 정보 동의 → 외부 서비스(카카오·TMAP) 동의 |
| 3 | 홈 | 지도와 내 주변에 열린 방 카드, 아래쪽 "현재 내 방" |
| 4 | 어디로 갈까요? | 출발지·목적지를 검색하면 경로·예상 시간이 나오고, 비슷한 동선의 방을 추천 |
| 5 | 방 참여 / 새 방 만들기 | 방 소개(출발지·목적지, 출발 시각, 인원, 1인 예상 요금)를 보고 참여하거나 직접 방을 만듦 |
| 6 | 이동 중(방) | 남은 시간, 만날 장소, 좌석, 1인 요금, 채팅. 모두 "확정"하면 약속 완료 |
| 7 | 함께 타기 | 만날 장소에서 만나 택시를 잡고 요금을 나눔 |

## 3. 주요 기능

### 비슷한 동선 찾기 (매칭)
- **출발지와 목적지가 모두 500m 안**에 있는 방을 후보로 보여 줍니다.
- 출발 시각이 비슷한지(약 ±30분), 경로가 얼마나 겹치는지, 돌아가는 시간이 얼마나 되는지로 순서를 매깁니다.
- 카드에는 "출발 0m · 경로 100%" 같은 태그로 왜 추천됐는지 보여 줍니다.

### 요금 나누기
- 카카오모빌리티 길찾기가 알려 주는 **예상 택시요금**을 방에 함께 탄 인원으로 나눠 "1인 예상 요금"을 보여 줍니다.
- 실제 결제와 정산은 탑승자끼리 직접 합니다.

### 방과 약속
- 방장은 방을 만들 때 탑승 인원(본인 포함 2~4명), 큰 짐 가능 여부, 소개글, **같은 성별만** 옵션을 고를 수 있습니다.
- 만날 장소는 기본으로 방 출발지이고, 방장이 "약속 바꾸기"에서 장소·출발 시간을 바꿀 수 있습니다.
- 출발 시간은 앱 안의 달력과 시간 선택(5분 단위, 7일 이내)으로 고릅니다.
- 약속이 바뀌면 모든 사람이 다시 "확정"해야 합니다.

### 채팅과 장소 카드
- 방 안에서 채팅으로 조율합니다. 전화번호 같은 개인정보는 나누지 말라는 안내가 항상 보입니다.
- 채팅에 "만나는 지점을 OO로 바꿀까요?", "목적지를 OO로 바꿀까요?"처럼 장소가 나오면, 그 장소를 카카오에서 찾아 **카드**로 띄웁니다.
  - 방장: "만날 장소로" 또는 "목적지로" 바로 변경
  - 참여자: "방장에게 제안하기"

### 도보 경로
- 홈에서 방 카드를 누르면, 내 위치에서 방 출발지까지 **걸어서 몇 m, 몇 분**인지(TMAP 보행자 경로) 확인한 뒤 참여할 수 있습니다.

### 안전과 운영
- 불편한 메시지나 사용자는 신고할 수 있고, 운영자 화면에서 처리합니다.
- 방장은 참여자를 내보낼 수 있고, 내보내진 사람은 바로 알림을 받습니다.

## 4. 개인정보는 어떻게 다루나요?

| 정보 | 다른 사람에게 보이는 방식 |
| --- | --- |
| 내 정확한 위치 | 보이지 않음. GPS는 필요할 때 한 번만 읽고 저장하지 않음 |
| 방 출발지·목적지 | 검색으로 고른 **공공장소 이름**(예: 정왕역 4호선)과 약 100m 단위로 흐린 위치. 주소는 보이지 않음 |
| 방 경로 | 양 끝 200m를 잘라 낸 경로만 보임 |
| 성별 | 다른 사람에게 보이지 않음. "같은 성별만" 방에 들어갈 수 있는지 판단할 때만 사용 |
| 카카오 계정 | 카카오 토큰은 저장하지 않음. 카카오 회원번호와 닉네임만 사용 |

## 5. 화면 구성 (PC와 휴대폰)

- **휴대폰**으로 접속하면 바로 모바일 앱이 열립니다. 지도 위에 아래 시트가 올라오는 구조입니다.
  - 화면 높이가 짧은 기기(예: 아이폰 사파리)에서는 글자·여백을 조금 줄인 컴팩트 모드로 보입니다.
- **PC**로 접속하면 서비스 소개 페이지가 열리고, **사용해보기**를 누르면 왼쪽에는 사용 가이드, 오른쪽에는 휴대폰 프레임 안의 실제 앱이 나옵니다.
- PC에서 모바일 화면을 바로 보고 싶으면 주소 뒤에 `?view=mobile`을 붙입니다.

## 6. 어떻게 만들어졌나요? (기술 구조)

```
[휴대폰 / PC 브라우저]
        │  웹 화면 (React)
        ▼
[GitHub Pages]  ── 프론트엔드 정적 파일
        │  API 요청 (HTTPS, WebSocket)
        ▼
[백엔드 서버 (Spring Boot)] ── [PostgreSQL + PostGIS]  위치·경로 저장
        │                     └ [Redis]  방 참여 동시성 잠금
        ▼
[외부 API]  카카오 로컬(장소 검색) · 카카오모빌리티(경로·택시요금) · TMAP(도보 경로) · 카카오 로그인
```

| 구분 | 사용 기술 |
| --- | --- |
| 프론트엔드 | React 18, TypeScript, Tailwind CSS, Vite, 카카오 지도 JS SDK, react-day-picker |
| 백엔드 | Java 21, Spring Boot 3.5, Flyway(DB 버전 관리) |
| 데이터 | PostgreSQL 16 + PostGIS(거리 계산), Redis 7 |
| 배포 | GitHub Pages(프론트), 개인 PC 백엔드 + Cloudflare 임시 터널(공개 테스트) |

백엔드는 기능별 모듈로 나뉘어 있습니다.

| 모듈 | 맡은 일 |
| --- | --- |
| identity | 회원, 로그인(카카오·닉네임), 동의, 성별 |
| trip | 사용자가 만든 이동 계획(출발지·목적지·시간)과 경로 |
| matching | 비슷한 동선의 방 찾기와 점수 계산 |
| rideroom | 방 만들기·참여·약속·확정 |
| conversation | 채팅(WebSocket) |
| moderation | 신고와 운영자 처리 |
| externalmobility | 카카오·TMAP API 연결 |

## 7. 직접 실행해 보기

**화면만 보기 (키·서버 없이)**: 브라우저 안의 가상 데이터로 전체 흐름을 체험할 수 있습니다.

```bash
cd frontend
npm install
npm run dev    # http://127.0.0.1:5173
```

**전체 실행 (실제 지도·경로)**: Docker로 DB를 켜고, 백엔드를 실행하고, 프론트를 `http` 모드로 켭니다. 필요한 키(카카오 REST·JavaScript, TMAP)는 각자 발급해 git에 올라가지 않는 `.env` 파일에 넣습니다. 자세한 순서는 저장소의 `README.md`를 보세요.

## 8. 용어 정리

| 용어 | 뜻 |
| --- | --- |
| 방 | 같은 방향으로 함께 탈 사람들의 모임. 방장 1명 + 참여자 |
| 방장 | 방을 만든 사람. 만날 장소·출발 시간·목적지를 바꿀 수 있음 |
| 만날 장소 | 함께 택시를 잡을 곳. 기본은 방 출발지 |
| 확정 | 약속(장소·시간)에 동의한다는 표시. 모두 확정하면 약속 완료 |
| 1인 예상 요금 | 예상 택시요금 ÷ 탑승 인원 |
| mock 모드 | 서버 없이 브라우저 안의 가상 데이터로 돌아가는 체험 모드 |
| 터널 | 개인 PC의 백엔드를 인터넷에 임시로 공개하는 통로. 켤 때마다 주소가 바뀜 |

## 9. 현재 한계와 주의 사항

- **시험판입니다.** 공개 테스트는 개발자 PC에서 백엔드와 터널이 켜져 있을 때만 동작합니다.
- 닉네임 로그인은 비밀번호가 없어 테스트용입니다. 실제 운영에서는 끄고 카카오 로그인만 써야 합니다.
- 실제 카카오 계정 로그인과 실제 아이폰 화면은 추가 확인이 필요합니다.
- 유상 택시 동승 중개의 적법성(여객자동차 운수사업법 등), 위치정보사업 신고, 외부 API 이용약관 준수 여부는 **검토되지 않았습니다.** 운영 전에 반드시 확인해야 합니다.
